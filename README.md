Data and code for "Biological, freshwater, and marine drivers of 
age at maturity in wild Chinook salmon" by Jennifer L. Gosselin, 
Benjamin P. Sandford, Caitlin S. O'Brien, and Eric R. Buhle, 
published in Canadian Journal of Fisheries and Aquatic Sciences.

Run the scripts in the "src" folder in the following order:

0_data_subset.Rmd

1_covariate_data.Rmd

2_brms_probit_models.R

3_tables_figures.R
